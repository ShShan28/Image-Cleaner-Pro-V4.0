# 🗞️ Image Cleaner Pro V4.0
**Professional AI Restoration for Historical Newspaper & Document Archives**

Image Cleaner Pro is a high-performance AI-powered desktop application designed to restore, colorize, and digitize historical document scans. It specifically excels at processing high-resolution newspaper archives, removing scanner artifacts, and generating searchable digital libraries.

## ✨ Key Features
*   **Dual-Mode AI Restoration**: Gold Standard (B&W) and AI Full Colorization.
*   **Intelligent Auto-Crop**: Automatically detects and removes scanner borders.
*   **2x Super-Resolution**: Built-in upscaling for high-quality printing.
*   **Advanced OCR (English & Tamil)**: Powered by Tesseract-OCR with searchable PDF generation.
*   **Parallel Batch Processing**: Multi-core CPU optimization for large archives.
*   **Zero-Config Deployment**: Robust portable scripts for auto-installation of Python and dependencies.

## 🛠️ Technology Stack
*   **Backend**: Python 3.10+, OpenCV, NumPy
*   **AI**: Caffe Framework (Colorization)
*   **OCR**: Tesseract-OCR v5.3+
*   **UI**: Streamlit

## 🚀 One-Click Setup
This project includes a powerful `setup.bat` that:
1. Automatically detects or installs Python 3.12 via `winget`.
2. Configures a local virtual environment.
3. Downloads Tesseract-OCR and required AI models.
4. Handles all dependencies silently.

### To Run:
Simply execute `run_app.bat` in the root folder.
